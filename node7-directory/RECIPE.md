# NODE7 Recipe Installation

Copy `node7-directory` into your NODE7 resources folder and add the following after `node7-core`:

```cfg
ensure node7-directory
```

`node7-jobcenter` is optional but should start before the directory when employment-board buttons are used.

PAGE UP is read directly through the RedM control hash. No key-binding command or rebinding step is required.

Category switching uses native RedM ledger navigation sounds (`NAV_LEFT` / `NAV_RIGHT` from `Ledger_Sounds`).
